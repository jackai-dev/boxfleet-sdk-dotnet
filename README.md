# BoxFleet .NET / C# SDK (BoxFleetSdk · .NET 8+)

> **Official SDK for BoxFleet (`boxfleet` / `boxfleek` / `jackai-box`)** — Generated by **[OmniWrap](https://omniwrap.dev)** from the canonical OpenAPI 3.1 contract (`openapi/boxfleet.openapi.yaml`) and qualified inside a live **E2B Firecracker MicroVM** via BoxFleet.

---

## Installation

```bash
git clone https://github.com/jackai-dev/boxfleet-sdk-dotnet && dotnet build
```

## Quick Start

```csharp
using BoxFleetSdk;

var client = new Client(new ClientOptions
{
    BaseUrl = "https://boxfleet.io",
    BearerToken = Environment.GetEnvironmentVariable("BOXFLEET_API_KEY")
});
var catalog = await client.Cloud.GetWhiteLabelCloudCatalogAsync();
```

| `system` | `getHealth`, `getCapabilities`, `listProviders`, `listMods` | Inspect 66+ providers, 9 AI coding client mods, and runtime limits |
